# デスクトップから体験談データを確認する方法

## 📋 概要

体験談データをデスクトップから確認・管理する方法を3つ紹介します。

## 🎯 方法1: Prisma Studio（GUIツール）⭐ 推奨

Prisma Studioは、データベースの内容をブラウザで確認・編集できるGUIツールです。

### 起動方法

```bash
cd backend
npm run db:studio
```

ブラウザで `http://localhost:5555` が自動的に開きます。

### 使い方

1. **左側のテーブル一覧から `Experience` を選択**
2. **体験談一覧が表示されます**
3. **各体験談をクリックして詳細を確認**
4. **編集・削除も可能**（開発環境のみ推奨）

### メリット

- ✅ 視覚的にデータを確認できる
- ✅ 検索・フィルター機能がある
- ✅ データの編集・削除が簡単
- ✅ ユーザー情報も同時に確認できる

### 注意事項

- 本番環境では使用しないでください
- データベースに直接アクセスするため、慎重に操作してください

---

## 🌐 方法2: 管理者画面（Webアプリ）

Webアプリの管理者画面から体験談を確認・管理できます。

### アクセス方法

1. **管理者アカウントでログイン**
   - 法人コード: `TEST0001`
   - 社員番号: `ADMIN001`
   - パスワード: `Admin123!`

2. **管理者ダッシュボードにアクセス**
   - URL: `http://localhost:3000/admin`

3. **「体験談管理」をクリック**
   - URL: `http://localhost:3000/admin/experiences`

### 機能

- ✅ 体験談一覧表示
- ✅ キーワード検索
- ✅ カテゴリ・ステータスでフィルター
- ✅ ステータス変更（公開/下書き/アーカイブ）
- ✅ 体験談の削除
- ✅ 詳細ページへのリンク

### 画面構成

```
管理者ダッシュボード
├── クイックアクセス
│   ├── 部署管理
│   ├── ユーザー管理
│   ├── 体験談管理 ← ここ
│   └── お知らせ管理
└── 全社統計
```

## 📥 方法3: JSONエクスポート機能

管理者画面から体験談データをJSON形式でエクスポートできます。

### エクスポート方法

1. **管理者画面にアクセス**
   - `http://localhost:3000/admin/experiences`

2. **エクスポートボタンをクリック**（実装予定）
   - または、APIを直接呼び出す:
   ```bash
   curl -H "Authorization: Bearer <token>" \
     http://localhost:3001/api/admin/experiences/export \
     -o experiences_export.json
   ```

3. **ダウンロードしたJSONファイルを開く**
   - テキストエディタ（VS Code、Sublime Text等）
   - JSONビューアー（JSON Viewer等）

### エクスポートされるデータ形式

```json
{
  "experiences": [
    {
      "id": "exp-001",
      "age": 34,
      "gender": "MALE",
      "jobType": "OFFICE",
      "category": "PHYSICAL",
      "subcategory": "緊張型頭痛",
      "targetPerson": "SELF",
      "title": "タイトル",
      "content": "本文",
      "tags": ["タグ1", "タグ2"],
      "viewCount": 1247,
      "helpfulCount": 823,
      "createdAt": "2024-11-15T10:30:00Z"
    }
  ],
  "exportedAt": "2025-01-05T12:00:00Z",
  "total": 70
}
```

## 🔍 各方法の比較

| 方法 | 難易度 | 機能 | 推奨用途 |
|------|--------|------|----------|
| **Prisma Studio** | ⭐ 簡単 | 閲覧・編集・削除 | 開発中のデータ確認 |
| **管理者画面** | ⭐⭐ 普通 | 閲覧・管理・検索 | 本番環境での管理 |
| **JSONエクスポート** | ⭐⭐ 普通 | データのバックアップ | データのバックアップ・移行 |

## 💡 推奨ワークフロー

### 開発環境

1. **Prisma Studioでデータを確認**
   ```bash
   npm run db:studio
   ```

2. **必要に応じてJSONからインポート**
   ```bash
   npm run db:seed:experiences:json
   ```

### 本番環境（またはステージング）

1. **管理者画面でデータを確認**
   - `https://your-domain.com/admin/experiences`

2. **必要に応じてJSONエクスポート**
   - バックアップとして保存

## 🛠️ トラブルシューティング

### Prisma Studioが起動しない

```bash
# Prismaクライアントを再生成
cd backend
npm run db:generate

# 再度起動
npm run db:studio
```

### 管理者画面にアクセスできない

- 管理者権限があるか確認
- ログインしているか確認
- バックエンドAPIが起動しているか確認

### JSONエクスポートが失敗する

- 管理者権限があるか確認
- バックエンドAPIが起動しているか確認
- ネットワークエラーがないか確認

## 📝 補足情報

### データベースの場所

- **開発環境**: ローカルのPostgreSQL
- **本番環境**: Supabase等のクラウドデータベース

### データの更新頻度

- **リアルタイム**: Prisma Studio、管理者画面
- **手動**: JSONインポート/エクスポート

### セキュリティ

- Prisma Studioは開発環境でのみ使用
- 管理者画面は認証が必要
- JSONエクスポートは管理者権限が必要
