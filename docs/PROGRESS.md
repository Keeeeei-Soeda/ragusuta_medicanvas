## 💡 開発メモ

### 統計機能の実装
- 期間別集計のロジックを汎用化
- ランキング計算はメモリ内で実施（将来的にはRedisでキャッシュ推奨）
- 部署の傾向分析でActivityLogとExperienceを結合して集計

### Mockデータ
- ActivityLog: 各ユーザーに10-40件の閲覧ログを生成
- Reaction: 各ユーザーに5-15件の「参考になった」を生成
- 過去30日以内のランダムな日時で作成

### セットアップコマンド追加
```bash
# すべてのシードデータを一括投入
npm run db:seed:all
```
