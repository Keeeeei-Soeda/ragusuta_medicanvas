## 📋 実装推奨順序

### 優先度1: マイページ機能 🔴
**理由**: ユーザーが自分の情報を確認・編集する基本機能
**実装内容**:
- `/profile` - プロフィール編集
- `/my/experiences` - 投稿履歴
- `/my/stats` - 個人統計（マイページ内）
- `/my/settings` - 設定

**所要時間**: 約2-3時間

---

### 優先度2: お知らせ機能（ユーザー向け） 🟡
**理由**: 管理者が作成したお知らせをユーザーが閲覧できるようにする
**実装内容**:
- ホーム画面にお知らせセクション追加
- `/announcements` - お知らせ一覧
- 未読/既読の管理
- 重要なお知らせのバッジ表示

**所要時間**: 約1-2時間

---

### 優先度3: マッチング機能（Phase 2） 🔴
**理由**: 体験談の価値を高める重要機能
**実装内容**:
- Google Sheets API連携
- マッチングアルゴリズム実装
- `/experiences/matched` - マッチング体験談表示
- ホーム画面にマッチングセクション追加

**所要時間**: 約3-4時間

---

### 優先度4: 教室一覧（Mock） 🟢
**理由**: Mock機能のため優先度低
**実装内容**:
- `/classes` - 教室一覧
- `/classes/[id]` - 教室詳細
- 予約ボタン（Mock）

**所要時間**: 約1時間
